## Experiencia en inteligencia de negocio (BI)

He desarrollado soluciones de **integración y análisis de datos** utilizando el ecosistema de Microsoft:

- **SSIS (SQL Server Integration Services):** Diseño de procesos **ETL** para extraer, transformar y cargar datos desde múltiples fuentes hacia SQL Server.  
- **SSAS (SQL Server Analysis Services):** Creación de **cubos OLAP** y modelos analíticos para optimizar la toma de decisiones empresariales.  
- **Power BI:** Construcción de paneles interactivos y visualizaciones dinámicas conectadas a modelos de datos.  
- **Automatización:** Implementación de tareas programadas y flujos de integración continua con Docker y SQL Agent.
